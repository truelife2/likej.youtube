本機辨識設定

這一頁控制「本機 Whisper + Gemini 文字」引擎的 Whisper 服務。設定一次就好， 之後按「開始」會自動把它叫起來，不需要再開黑色視窗。

Python

用 ComfyUI 內建的 Python 就好，裡面已經有 torch 與 transformers，不必另外安裝任何套件。

Whisper 模型

掃描會列出資料夾裡所有 HuggingFace 格式的 Whisper（含 config.json 的資料夾）。 turbo 準確度略低但快一倍；large-v3 慢一些、對口音與背景音更穩。

本機翻譯與配音（可選）

建議用 http 接本機 LLM（例如 Qwen3-4B，一句約 0.3 秒）；command 適合自己寫的翻譯腳本。 改完設定要「停止服務」再「啟動服務」。

選 edge 或 sapi 就不用填下面的指令，伺服器會用內附的 tts-edge.py／tts-sapi.ps1；下面的指令與網址只有選 command／http 時才需要。

任何能吃文字、吐 WAV 的模型都能接（Piper、Kokoro、CosyVoice2、BreezyVoice、Edge TTS…）。 細節見 local-asr\README.md。

連線

擴充功能預設連到 8791；改這裡之後也要在 popup 的「本機辨識服務」改成相同埠號。

開機自動啟動

不勾也可以：只要安裝過原生主機，按「開始」時會在需要時自動啟動。 勾起來只是讓第一部影片少等幾秒。

沒有原生主機（顯示「無法連上原生主機」）時，執行一次 native-host\install.cmd；或退而求其次手動執行 local-asr\start.cmd。
