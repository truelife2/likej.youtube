# YouTube 即時口譯（Chrome 擴充功能）

把 YouTube 直播／影片的聲音抓下來，即時翻成中文：

- **字幕**：原文＋譯文雙語字幕，浮在播放器上，可拖曳、可調大小
- **配音**（可選）：用 Gemini 的語音把譯文念出來，原音自動壓低
- **兩種引擎**：雲端 Gemini 即時口譯（有配音）／本機 Whisper + Gemini 文字（只有字幕、延遲固定）

純前端擴充功能，沒有中間伺服器。Gemini API Key 只存在你自己的瀏覽器裡。

> 想了解內部怎麼運作（音訊管線、為什麼切句、各種設計取捨），看 [`docs/DESIGN.md`](docs/DESIGN.md)。

## 1. 系統需求

| 項目 | 需求 |
| --- | --- |
| 瀏覽器 | Chrome 或 Edge（Chromium 116 以上） |
| Gemini API Key | 必要。[Google AI Studio](https://aistudio.google.com/apikey) 免費申請 |
| 本機 Whisper（可選） | Windows、NVIDIA GPU（建議 8 GB VRAM 以上）、已安裝 ComfyUI（借它的 `python_embeded`，**不用另外安裝 Python 套件**） |

只做「Gemini 即時翻譯」的話，只要有 API Key 就能跑，不需要 GPU、不需要安裝任何東西。

## 2. 安裝

### 2-1 載入擴充功能（必做）

1. 把這個資料夾放在固定位置（不要放在會被同步／清理的資料夾）
2. 開 `chrome://extensions`
3. 右上角開啟 **開發人員模式**
4. 按 **載入未封裝項目**，選擇這個資料夾
5. 建議按右上角的圖釘，把圖示釘到工具列

> 之後每次我更新程式，你都要回來這裡按一次 **重新載入**（版本號會變，例如 `1.11.8`）。

### 2-2 取得 Gemini API Key（必做）

1. 到 [Google AI Studio › API keys](https://aistudio.google.com/apikey)
2. 建立 API Key 並複製
3. 打開擴充功能，貼到「Gemini API Key」欄位（會存在 `chrome.storage.local`，只有這台電腦的這個擴充功能讀得到）

### 2-3 安裝本機辨識服務（只有想用「本機 Whisper」才需要）

這一步讓擴充功能可以**自己啟動／停止** Whisper 服務，之後完全不用開黑窗。

1. 先完成 2-1，打開 popup 右上的 **⚙** → 記下頁面上的「擴充功能 ID」
2. 在這個專案資料夾執行（用 `cmd` 或 PowerShell 都可以）：

   ```
   native-host\install.cmd
   ```

   如果它抓不到你的擴充功能 ID，就自己帶上：

   ```
   native-host\install.cmd <你的擴充功能ID>
   ```

3. 回到 `chrome://extensions` 按 **重新載入**
4. 開 **⚙** 設定頁 → 按 **啟動服務**，狀態應變成「服務正常（GPU）」

安裝腳本會做的事：編譯一個小啟動器 `native-host\launcher.exe`、寫入原生主機設定、註冊到 Chrome 與 Edge。它不會安裝任何 Python 套件。

## 3. 第一次使用（5 步）

1. 開一支 YouTube 影片或直播（`https://www.youtube.com/watch?v=...`）
2. **點工具列上的擴充功能圖示**（Chrome 要求由使用者點擊，才能授權抓分頁音訊）
3. 貼上 API Key → 按模型欄旁邊的 **↻** 查詢你的金鑰可用哪些模型（名稱常變動，不要死背）
4. 選「翻譯成」的語言、選「輸出」（配音＋字幕／僅字幕）
5. 按 **開始翻譯**

播放器上會出現字幕框，講者一開口就會開始翻譯。要停止按 popup 的「停止」或字幕框右上角的 **✕**。

### 建議第一次這樣試

1. 先用 **僅字幕** + `gemini-3.5-live-translate-preview`：延遲最低、最容易看出翻譯對不對
2. 字幕穩定後再切 **語音配音 + 字幕**，把「原音音量」留在 25% 左右、「配音時的原音」用預設 12%
3. 如果影片本身有字幕，兩邊對照最快能看出哪裡漏譯

### 兩種引擎怎麼選

| | **Gemini 即時翻譯**（預設） | **本機 Whisper + Gemini 文字** |
| --- | --- | --- |
| 做什麼 | Gemini Live 直接聽音訊、邊翻邊講中文 | 本機 Whisper 轉文字 → Gemini 文字模型翻中文 |
| 延遲 | 1.5–3 秒起，**快語速會越積越多** | **固定約 2 秒**，不會越拖越久 |
| 配音 | 有 | 無（只有字幕） |
| 需要 | API Key | API Key + 跑一次 `native-host\install.cmd` |
| 適合 | 想聽配音、一般語速 | 長時間直播、快語速、只要看懂 |

## 4. Popup 每個欄位在設什麼

### 引擎

| 欄位 | 說明 |
| --- | --- |
| 翻譯引擎 | **Gemini 即時翻譯**：有配音，但模型輸出速度有上限。**本機 Whisper + Gemini 文字**：只有字幕，延遲固定。 |
| 本機辨識服務 | 服務位址，預設 `http://127.0.0.1:8791`。旁邊 **▶** 啟動服務、**↻** 重新檢查、⚙ 開設定頁。 |
| 原文語言 | 本機模式用。**建議直接選 English**：比自動偵測快也準；選錯會出現亂碼或殘字。 |
| Whisper 模型 | 本機模式用。`large-v3-turbo` 快、`large-v3` 準。切換約數秒，不用重啟服務。 |
| 翻譯用文字模型 | 本機模式用。**要選一般文字模型**（例 `gemini-2.5-flash-lite`）。選到 `transcribe`／`live` 這類模型會失敗，欄位下方會出現警告。 |

### Gemini 模型

| 欄位 | 說明 |
| --- | --- |
| 模型 | 按 **↻** 列出你金鑰可用的即時語音模型。**`gemini-3.5-live-translate-preview`** 是 Google 專為即時口譯做的，連續串流、延遲最低，建議用它。 |
| 翻譯成 | 目標語言，下方會顯示對應的語言代碼（例 `zh-Hant`）。 |
| 輸出 | **語音配音 + 字幕** 或 **僅字幕**。注意：2026 年起 Live API 的模型都只輸出語音，字幕是語音的逐字稿，所以「僅字幕」只是不播放，**不會比較快也不會比較省**。 |
| 切句方式 | **自動切句**（預設）：偵測到停頓才把一句送出去，譯文較連貫。**連續串流**：不切句，延遲低但容易片段化。用即時翻譯模型時這項會被忽略。 |
| 收音靈敏度 | 太小聲沒反應就調高；背景音樂一直誤觸發就調低。 |
| 嗓音 | 只對 native-audio 對話模型有效（已標女聲／男聲）。即時翻譯模型會**跟著講者的音色**，選什麼都一樣。 |
| 配音語言代碼 | 例 `ja-JP`、`en-US`。留空＝模型自動判斷。 |

### 音量與節奏

| 欄位 | 說明 |
| --- | --- |
| 翻譯音量 | 配音音量（0–150%），播放中拖動**即時生效**。 |
| 原音音量 | 你聽到的原音**基準**音量，播放中即時生效。 |
| 配音時的原音 | 譯音說話時，原音要壓到多少：不壓低／50%／25％／**12%（預設）**／5%。選「不壓低」就是兩個聲音一樣大。 |
| 翻譯積太多時自動暫停 | 累積的語音超過設定秒數就暫停影片，讓模型追上；降到設定值內自動繼續。兩個秒數都可以在播放中改。 |
| 累積幾秒才暫停 | 預設 45 秒（可選 15–120）。快語速建議 15–30。 |
| 翻到剩幾秒恢復 | 預設 10 秒（可選 0–30）。 |
| 在字幕上標示音訊分段 | 診斷用（預設開）。字幕裡會出現 `│`（換段）與 `⏸6.4s(來源無聲)`／`⏸6.4s(譯音慢)`：前者代表那段時間分頁本來就沒聲音（不用修），後者代表來源有聲音但譯音晚到（模型或網路）。覺得干擾可關掉。 |

> **為什麼會有兩個音量？** YouTube 的滑桿在播放層，拉小會讓擷取到的音訊也變小（連帶影響 VAD 與 Whisper 的辨識品質）。擴充功能的「原音音量」是擷取之後的增益，只影響你聽到的聲音，不影響辨識。

## 5. 字幕框操作

| 動作 | 效果 |
| --- | --- |
| 拖曳標題列 | 移動位置（會記住） |
| **A+ / A−** | 調整字級（會記住） |
| **✕** | 停止翻譯 |
| 左側小圓點 | 灰＝未啟動、黃＝連線中、綠＝連線中、藍＝正在收音 |

翻譯文字會**持續累積**，超過約 120 字才沿句子邊界捲掉最舊的，不會一句一閃就消失。不同句子會用**白／淺藍兩色輪替**，方便看出新的一句從哪裡開始。

## 6. 診斷數字怎麼看

字幕框左下角那行小字是即時診斷，例如：

```
延遲 2.4s・待譯 12s・峰值 46%
```

| 數字 | 意思 | 正常範圍 |
| --- | --- | --- |
| `延遲 x.xs` | 從你出聲到第一個譯文字出現（**體感延遲就看這個**） | 即時翻譯 1.5–3 秒；對話模型 3–6 秒 |
| `待譯 Ns` | 已送進模型但還沒翻出來的語音秒數 | 會上下波動；**持續變大**代表模型追不上 |
| `落後 Ns` | 已送出音訊秒數 − 已收到譯音秒數 | 同上，持續變大就要讓它暫停追上 |
| `峰值 N%` | 最近 2 秒擷取到最大音量 | 講話時 30–90%；個位數代表幾乎沒收到聲音 |
| `送稿 1.00x` | 實際送出的音訊速率 | 應該接近 1.00；明顯大於 1 代表播放速度不是 1x（程式會自動調回） |

`待譯` 或 `落後` 超過你設定的門檻時，程式會自動暫停影片，等模型翻完再繼續（可在 popup 關掉或調整秒數）。

## 7. 設定頁（本機服務）

Popup 右上角 **⚙** 開啟，只有「本機 Whisper」模式會用到。

| 項目 | 說明 |
| --- | --- |
| 服務狀態 | 綠點＝正常，會顯示使用 GPU 或 CPU |
| 啟動／停止／重新檢查 | 控制 Whisper 服務，不必開黑窗 |
| Python 路徑 | 用哪個 Python 執行服務，可自動偵測。預設是 ComfyUI 的 `python_embeded` |
| 模型資料夾 | 到哪個資料夾找 Whisper 模型，預設 `...\ComfyUI\models\audio_encoders` |
| Whisper 模型 | 掃描資料夾後列出可用模型，選了就熱切換（不用重啟） |
| 連接埠 | 預設 8791，改了 popup 的服務位址也要一起改 |
| 開機自動啟動 | 勾選後開機就自動跑服務 |
| 擴充功能 ID | 原生主機註冊用；若顯示「找不到原生主機」，複製這串執行 `native-host\install.cmd <ID>` |

## 8. 疑難排解

| 症狀 | 原因 / 解法 |
| --- | --- |
| **按「開始」沒反應、或提示「無法擷取分頁音訊」** | 關掉 popup，**重新點工具列圖示**再按開始。Chrome 只在使用者點擊後授權抓分頁音訊。 |
| **字幕框顯示「翻譯中」卻一直沒字** | 換頁、換影片或重新載入擴充功能後，舊分頁的內容腳本會失效。程式會自動重新注入；若仍發生，**重新整理該 YouTube 分頁**再按開始。 |
| **`chrome.runtime.connectNative is not a function`** | 擴充功能還是舊版（權限沒生效）。設定頁有「重新載入擴充功能」按鈕，或到 `chrome://extensions` 按重新載入，再回來按啟動服務。 |
| **`Specified native messaging host not found`** | 原生主機沒註冊成功。複製設定頁的「擴充功能 ID」，執行 `native-host\install.cmd <ID>`，再重新載入擴充功能。 |
| **連不上本機辨識服務（127.0.0.1:8791）** | 開 ⚙ 看服務狀態，按 **▶ 啟動服務**。想手動也可以執行 `local-asr\start.cmd`。第一次啟動要載入模型（2–10 秒）。 |
| **本機模式只出現「謝謝」「對」「Thank you.」** | 已修：舊版只送句子尾巴 0.1 秒給 Whisper。更新到 1.10.1 以上即正常；音樂／靜音的幻覺也會被過濾。 |
| **本機模式 `HTTP 404`** | 「翻譯用文字模型」不存在於你的金鑰。按 ↻ 重選一般文字模型（例 `gemini-2.5-flash`）。 |
| **本機模式 `HTTP 429`** | 免費額度用完。程式會自動重試，仍不行就暫停 60 秒（句子會保留，最多 90 句）。可換文字模型或等隔天額度重置。 |
| **越翻越慢、落後 20–30 秒** | 模型輸出速度跟不上講者。字幕框的 `待譯`／`落後` 會顯示實況；把「翻譯積太多時自動暫停」打開，讓它暫停追趕。客戶端不會丟音訊，所以不會缺字。 |
| **字幕很慢，講一堆才出現一句** | 你用的是**對話模型**（要等句子講完才回）。換成 `gemini-3.5-live-translate-preview`（連續串流）。 |
| **字幕每幾個字就斷一行、很零碎** | 短片段會被押 1.4 秒接成一句，且譯文用雙色輪替、不換行。若仍零碎，把「收音靈敏度」調低（背景音樂容易誤觸發）。 |
| **顯示「幾乎收不到聲音（峰值 N%）」** | 峰值 < 3% 才會警告。檢查分頁是否被靜音、系統音量、輸出裝置。 |
| **沒有女聲，聲音是講者本人** | 即時翻譯模型會複製講者音色，不能指定嗓音。要固定女聲只能換 native-audio 對話模型（翻譯會慢很多）。 |
| **翻譯跑約 30 秒就自己停掉、變半透明** | 已是舊版問題（offscreen 的音訊播放 reason 導致被回收）。更新後正常；若 popup 顯示「背景程序被瀏覽器關閉」，重新按開始。 |
| **有字幕沒配音** | 輸出選了「僅字幕」，或「翻譯音量」被拉到 0。 |
| **翻譯只出來幾個字、聲音重疊** | 舊版問題，更新後已修正（音訊併段播放、不重疊）。 |
| **配音一句話中間停很久，或句與句之間多一段空白** | 三個原因：①模型回傳的每句譯音前後各帶一小段靜音 → 已自動剪掉（只留 0.06 秒頭、0.1 秒尾）；②模型音訊**句中夾了長空白**（幾秒的「停頓再繼續」）→ 現在會壓成 0.06 秒，不再原樣播出；③排程判斷句尾太早 → 現在「講者停頓 0.7 秒」或「句尾標點 + 音訊真的停了 0.7 秒」才播，接句緩衝也降到 0.12 秒，而且**逐字稿還停在逗號（句子沒完）時最多等 20 秒也不切句**，模型中途卡 6–7 秒不會把同一句切成兩段。「講者停頓」是直接看擷取到的波形，不是等辨識或模型回傳，所以沒有解析延遲。 |
| **怎麼判斷停頓是模型還是程式造成的** | 字幕上的 `│` 是換段銜接（沒有空白），`⏸0.8s` 是「這句前面真的停了 0.8 秒」。停頓若都出現在 `⏸` 後面 → 譯音晚到（模型或網路）；若同一段文字中間卡住 → 模型回傳的音訊本身有空白。 |
| **字幕在劇院／全螢幕看不到** | 已處理全螢幕切換；失效請重新整理頁面。 |

| **切到別的網頁還在翻譯** | 已修：離開影片頁或整頁跳走時會自動停止。 |

## 9. 費用與額度

- 以 Gemini Live 語音計價，一小時直播大約幾十美分到一兩美元（依模型與匯率而異，以[官方定價](https://ai.google.dev/pricing)為準）。
- 免費層額度很小（某些 native-audio 模型每日只有十幾次請求），**長片一定會用完**。建議在 AI Studio 設定用量上限，不要用主力金鑰。
- 本機 Whisper 模式的辨識在你的 GPU 上跑，不花 Gemini 的語音額度；只有「翻成中文」那一步會用文字模型的額度（很省）。

## 10. 限制與注意事項

- **必須手動點擴充功能圖示**：分頁重新載入後授權失效，要重新按開始。
- **只翻譯「說話」的內容**：唱歌、純音樂會被忽略；多人搶話可能漏一句。
- **Live API 模型都只輸出語音**：字幕是語音的逐字稿，所以「僅字幕」不會比較快。
- **擷取的是你自己瀏覽器正在播放的音訊**：僅供個人收看輔助，不要把翻譯內容再散布。
- **API Key 存在 `chrome.storage.local`**：只有這台電腦的這個擴充功能讀得到，不要連同 key 打包分享。

### 換掉圖示

圖示是程式畫的（紅底白十字），原始碼在 `tools/make-icons.cjs`。想改顏色或形狀，改這個檔案裡的常數（`RED_TOP`、`RED_BOTTOM`、十字粗細），再執行：

```bash
node tools/make-icons.cjs
```

它會重新產生 `icons/icon16.png`、`icon32.png`、`icon48.png`、`icon128.png`（純 Node、零依賴），重新載入擴充功能後就會換掉。

### 離線驗證（不需要 API Key）

```bash
node test-selftest.cjs    # 音訊降採樣、base64、setup 結構、音量、語言代碼
node test-flow.cjs        # 用假 WebSocket 走完整連線流程
node test-segment.cjs     # 用真實影片音訊驗證切句品質
node tools/test-playback.cjs  # 配音排程：一句不能被切成好幾段、音訊不丟
```

### 更新版本

每次更新檔案後：`chrome://extensions` → 這支擴充功能的 **重新載入** → 關掉 popup 再重開。版本號在 `chrome://extensions` 的卡片上（或 `manifest.json` 裡）。
