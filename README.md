# YouTube 即時口譯（Chrome 擴充功能）

把 YouTube 的聲音即時翻成中文：原文＋譯文雙語字幕浮在播放器上，可選擇用中文語音配音（原音自動壓低）。純前端，沒有中間伺服器；API Key 只存在你自己的瀏覽器裡。

兩種引擎：

- **Gemini 即時翻譯**（預設）：有配音，延遲約 2–3 秒起，快語速會越積越多。
- **本機 Whisper + Gemini 文字**：字幕延遲固定約 2 秒，適合長時間或快語速；伺服器接上 TTS 後也可配音，勾「翻譯也走本機」還能改用本機 LLM（Qwen3-4B）翻譯、完全不吃 Gemini 額度（見 [`local-asr/README.md`](local-asr/README.md)）。

## 系統需求

| 項目 | 需求 |
| --- | --- |
| 瀏覽器 | Chrome 或 Edge（Chromium 116 以上） |
| Gemini API Key | 必要，[AI Studio](https://aistudio.google.com/apikey) 免費申請 |
| 本機 Whisper（可選） | Windows、NVIDIA GPU（建議 8 GB VRAM）、ComfyUI 的 `python_embeded`（不用另裝套件） |
| 本機配音（可選） | 任何能輸出 WAV 的語音模型；內附 Windows SAPI 與 Edge TTS 兩支指令稿，接上 `/tts` 就能用 |
| 本機翻譯（可選） | 本機 LLM（Qwen3-4B GGUF 約 2.4 GB + llama.cpp，建議；一句約 0.3 秒） |

## 安裝

1. **先取得檔案**。這是一份原始碼，不是商店安裝，所以要先把專案抓到電腦上：

   - 有 Git（Git for Windows、TortoiseGit、VS Code 都可以）：`git clone https://github.com/truelife2/likej.youtube.git`
   - 沒裝 Git：到 GitHub 專案頁按 **Code → Download ZIP**，解壓縮到固定位置

   放固定位置（例如 `G:\impl\likej.youtube`），**不要**放在會被同步或定期清理的資料夾，否則擴充功能會失效。之後更新就是對這個資料夾 `git pull`（或重新下載覆蓋）。
2. `chrome://extensions` → 開啟**開發人員模式** → **載入未封裝項目** → 選上面那個資料夾。
3. 開 popup 貼上 API Key。
4. 只有要用本機 Whisper 才需要：執行 `native-host\install.cmd`（只需一次；抓不到 ID 就帶上，設定頁有顯示）。

## 使用

1. 開 YouTube 影片或直播，**點工具列圖示**（Chrome 要求由使用者點擊才授權抓分頁音訊）。
2. 選模型（不確定就按 **↻** 查金鑰可用哪些）與目標語言 → 按**開始翻譯**。
3. 停止按 popup 的「停止」或字幕框右上 **✕**。

字幕框可拖曳、**A+ / A−** 調字級；左側圓點：灰＝未啟動、黃＝連線中、綠＝已連線、藍＝正在收音。譯文會持續累積，白／淺藍兩色輪替區分句子。

## 欄位

| 欄位 | 說明 |
| --- | --- |
| 模型 | 預設 `gemini-3.5-live-translate-preview`（Google 專為即時口譯設計，延遲最低）。`3.8-live` 這類對話模型要等整句講完才回，慢很多。 |
| 輸出 | 配音＋字幕／僅字幕。Live 模型只輸出語音，字幕是那段語音的逐字稿，所以「僅字幕」不會更快。 |
| 嗓音 | 只對 native-audio 對話模型有效；即時翻譯模型會複製講者音色。 |
| 收音靈敏度 | 太小聲沒反應就調高；背景音樂一直誤觸發就調低。 |
| 翻譯音量／原音音量 | 0–150%／0–100%，播放中拖動即時生效。原音是基準值。 |
| 配音時的原音 | 譯音說話時原音壓到多少（預設 12%）；選「不壓低」就是兩者同音量。 |
| 自動暫停 | 累積語音超過門檻就暫停影片讓模型追上（預設 45 秒），翻到剩 10 秒恢復；關掉就不會動你的影片。 |
| 在字幕上標示音訊片段 | 診斷用：每個色塊（＝一次配音）結尾一個流水號，例如「一整段文字(1) 一整段文字(2)」。號碼出現的同時那一段正好開始唸，聽到哪一段接得怪，回報號碼就好。片段號不占字幕字數，字幕保留約 5–6 行。 |
| 原文語言／Whisper 模型／文字模型 | 本機模式用。原文語言建議直接選 English（選錯會出現亂碼）；文字模型要選一般模型（例 `gemini-2.5-flash-lite`）。 |
| 本機模式翻譯也走本機 | 本機模式用。打勾後譯文改由本機服務翻譯（建議接 Qwen3-4B，一句約 0.3 秒），完全不消耗 Gemini 額度；伺服器沒接上翻譯模型時自動退回 Gemini。 |

## 診斷數字

字幕左下的小字，例如 `延遲 2.4s・待譯 12s・峰值 46%`：

| 數字 | 意思 |
| --- | --- |
| 延遲 | 出聲到第一個譯文字出現（**體感延遲看這個**） |
| 待譯 | 送進模型但還沒翻出來的「有聲」語音秒數（連續串流引擎看這個） |
| 落後 | 已送出音訊 − 已收到譯音（對話模型看這個） |
| 峰值 | 最近 2 秒最大音量。講話 30–90%；個位數代表幾乎沒收到聲音 |

待譯或落後超過門檻時會自動暫停影片（可在 popup 關閉或調整）。

## 疑難排解

| 症狀 | 解法 |
| --- | --- |
| 按「開始」沒反應／無法擷取分頁音訊 | 關掉 popup，重新點工具列圖示再按開始。 |
| 字幕框顯示「翻譯中」卻沒字 | 重新整理該 YouTube 分頁再按開始（舊分頁的內容腳本已失效）。 |
| 越翻越慢、落後 20–30 秒 | 模型輸出跟不上講者。打開「自動暫停」讓它追；客戶端不會丟音訊，所以不會缺字。 |
| 字幕很慢，講一堆才出現一句 | 用到對話模型，換成 `gemini-3.5-live-translate-preview`。 |
| 配音斷斷續續、一句被切成好幾段 | 1.13.13 起配音以「色塊」為單位（字幕換色才整塊播出，號碼＝聽到的片段）。仍會斷就把「收音靈敏度」調低，減少背景音樂干擾切句；並確認模型是 `gemini-3.5-live-translate-preview`。 |
| 顯示「幾乎收不到聲音」 | 檢查分頁是否靜音、系統音量、輸出裝置。 |
| 沒有女聲 | 即時翻譯模型會複製講者音色；要固定女聲只能換 native-audio 模型（翻譯會慢很多）。 |
| 連不上本機辨識服務 | ⚙ 設定頁按 **▶ 啟動**（第一次要載入模型 2–10 秒）；手動也可執行 `local-asr\start.cmd`。 |
| `connectNative is not a function`／`native host not found` | 擴充功能沒重新載入，或原生主機沒註冊：先重載擴充功能；仍不行就 `native-host\install.cmd <ID>`。 |
| 本機模式 `HTTP 404`／`429` | 404：換一般文字模型。429：額度用完，程式會自動重試、暫停 60 秒，句子保留在佇列。 |
| 本機模式勾了配音卻沒聲音 | 本機服務還沒接上語音模型：開 popup 看服務狀態是否顯示「配音未接上」，並依 [`local-asr/README.md`](local-asr/README.md) 設定 `YTLT_TTS_BACKEND`。字幕不受影響。 |
| 本機模式勾了本機翻譯還是用掉額度 | popup 狀態若顯示「翻譯未接上」，代表服務沒設定 `translateBackend`（⚙ 設定頁 → 本機翻譯與配音）；接上後就不會再呼叫 Gemini。 |
| 本機配音沒聲音、popup 顯示「配音未接上」 | `ttsBackend` 還是 `none`，或服務是改設定前啟動的舊行程。填好指令後按「停止服務」再「啟動服務」。 |

## 費用與限制

- 依 Gemini Live 語音計價，一小時直播約幾十美分（[官方定價](https://ai.google.dev/pricing)）。免費層額度很小（部分模型每日十幾次請求），長片一定會用完。本機 Whisper 不花語音額度，勾「翻譯也走本機」連文字額度也不花；配音用內附的 SAPI 指令稿完全離線。
- 必須手動點圖示才能抓音訊；只翻「說話」的內容，唱歌與純音樂會被忽略。
- 擷取的是你自己瀏覽器正在播放的聲音，僅供個人收看輔助。
- API Key 不要連同擴充功能打包分享。
